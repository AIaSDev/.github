# FHNW BSc BAI — AI-assisted Software Development

Welcome to the GitHub organisation for the **AI-assisted Software Development** module in the FHNW BSc Business Artificial Intelligence programme.

## Start here

- [AI-SDLC documentation](https://docs.aisl.science/learning-and-resources/ai-sdlc) — canonical human-readable method documentation
- [AI-SDLC project template](https://github.com/AIaSDev/ai-sdlc-template) — executable repository starter for student projects
- [BAIssue](https://github.com/AIaSDev/BAIssue) — reference implementation

The repositories contain the operational artefacts and examples. The method itself, its lifecycle, terminology, publication links and version references are maintained in GitBook.

## Module focus

The module combines spec-driven development, Clean Architecture, test-first implementation, GitHub Projects, Codespaces, VS Code, GitHub Copilot and GitHub Actions. GitHub Classroom is not part of the workflow.
